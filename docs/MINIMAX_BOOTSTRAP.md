# 给 MiniMax Code 的开工任务

请在本仓库创建可编译的 visionOS App 骨架（SwiftUI + RealityKit），目标：

- 界面：简单聊天窗口 + 占位 3D 人（可用系统球体/占位模型）
- 网络：DeepSeek 流式聊天接口（Key 用环境变量，勿写死）
- 语音：MiniMax 流式 TTS（WebSocket t2a_v2_bidi），音频在设备播放
- 口型：先用音量驱动简单 jawOpen 占位；不要生成视频
- 文档：在 README 补充如何配置 Key、如何在模拟器运行

约束：个人开发、先模拟器；代码清晰可被 Cursor 继续改。
